# Marketplace

Claude Code загружает автоматически только корневой `CLAUDE.md`. Спецификация проекта и
менторская персона лежат в `.agents/CLAUDE.md` — без импорта ниже они в сессию не попадают.

@.agents/CLAUDE.md

## Где что лежит

- `.agents/CLAUDE.md` — системный промпт (менторский режим) и спецификация проекта.
- `.agents/TASKS.md` — глобальный бэклог. Дорожка **[I]** — делает агент, **[D]** — владелец.
- `.agents/MEMORY.md` — текущее состояние и таблица принятых решений.
- `.agents/SCENARIOS.md` — кросс-доменные сценарии.
- `AGENTS.md` — операционные правила для агентов: команды, конвенции, жёсткие запреты.
- `docs/agent-loop.md` — событийный цикл Claude ↔ Codex: состояния, токены, гарды.
- `docs/runbook.md` — пошаговая настройка и запуск цикла.
- `ops/` — развёртывание self-hosted раннеров на VPS.

## Два режима

По умолчанию действует менторский режим из `.agents/CLAUDE.md`: код не пишется без явной просьбы.

Исключение — автопилот: прогоны workflow из `.github/workflows/agent-*.yml`. Их промпты
(`.github/agents/*.md`) в первой строке объявляют режим автопилота и снимают запрет на
генерацию кода. Только на это. Все остальные правила проекта продолжают действовать.
